How I work

Every doc ships like production code.

Drafted against real user questions, peer-reviewed in Git, linted in CI, versioned, and continuously deployed. I start with evidence from support tickets, search queries, and onboarding drop-off, so documentation effort goes where readers actually struggle.

  • Peer-reviewed in Git
  • Prose linted in CI
  • Deployed on merge
  • Written for humans & AI retrieval
